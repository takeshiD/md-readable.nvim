# [I22] 画像の本文内表示

## 目的

png/jpg/svg/webp、可視領域で自動表示、外部画像は許可後のみ、未対応/失敗時にalt等を保持、window終了時の描画破棄。

## 入出力と対象範囲

画像target、許可状態、表示windowの可視範囲/配置 → 任意の画像描画またはfallback。

Mermaid入力処理はI23。動画再生は対象外。

## 先行Issue

- [I02 #3](https://github.com/takeshiD/md-readable.nvim/issues/3)
- [I15 #16](https://github.com/takeshiD/md-readable.nvim/issues/16)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/providers/image.lua、lua/md-readable/image/{capabilities,convert,cache,display}.lua

専用テスト・fixture: `tests/i22/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] png/jpg/svg/webpを対象に、対応端末/変換ツールがある場合に可視領域へ自動表示する。
- [ ] 外部画像は操作/configで許可するまで取得しない。変換ツールを自動インストールしない。
- [ ] ファイル名や入力をargvで渡し、入力変更でcacheを無効化し、失敗時はalt/filenameを保持する。
- [ ] WezTerm/Ghosttyでsplit/float/複数window/resize/scroll/closeを確認し、端末制限は明記する。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。
