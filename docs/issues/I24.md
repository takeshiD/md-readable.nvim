# [I24] ミニマップ

## 目的

既定非表示、開閉、読書表示の現在地への追従、ミニマップから本文へ移動、再描画後も対応維持。

## 入出力と対象範囲

読書表示の行・現在行・SourceMap・名前付き注釈 → 縮小表示と本文移動。

Git差分計算と診断取得はI30/I31。neominimap.nvimは不要。

## 先行Issue

- [I02 #3](https://github.com/takeshiD/md-readable.nvim/issues/3)
- [I15 #16](https://github.com/takeshiD/md-readable.nvim/issues/16)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/nav/minimap.lua、lua/md-readable/minimap/{render,session}.lua

専用テスト・fixture: `tests/i24/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] Brailleによる縮小、現在行表示、UTF-8/tab、操作による開閉・本文へ移動を内蔵し、既定では非表示。
- [ ] 縮小文字を使えない環境向けの簡略表示を選べる。
- [ ] set_annotations(provider_id, items)等でGit/LSPの独立入力を受け付け、更新/削除を個別に行える。
- [ ] 派生nofile bufferを対象にし、原文→表示→縮小座標の対応とresize/closeのcleanupを検証する。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
