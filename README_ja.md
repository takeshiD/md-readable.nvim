# md-readable.nvim

[English version](README.md)

このプラグインはmarkdownを読解することに長けたプラグインです。
以下の機能を有します。

- Appearance
    - markdown構文ハイライト
    - テーブルレンダリング
    - コードブロック
    - カラーテーマ切り替え
    - テーブル内/URLの長文省略表示
    - ローカルリンク, 外部リンクごとのアイコン表示
- Navigataion
    - ミニマップ
    - 見出しツリー
    - Focus Mode
    - 主要SSGの目次・前後
        - 対応SSG: mdBook, Docusaurus, MkDocs, Astro, Honkit, GitBook
- Formatting
    - テーブル整形
- Contents
    - 画像表示(png,jpg,svg,webpなど)
    - Mermaidダイアグラムレンダリング

一部Writingサポートもそなわっています。
- Writing
    - Read Buffer, Write Buffer カーソル同期

# Requirements
- Neovim >= 0.12
- (Optional) 画像表示: WezTerm, Ghosttyで実施
- (Optional) Mermaid: mermaid-cli, Mermaid
