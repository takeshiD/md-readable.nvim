## 受け入れ条件

- [ ] current/vert/float/source/close、各Navigation/Focus/theme/minimap/search/table操作をコマンドとLua APIに接続する。
- [ ] 必須全機能と全7SSGの対応表・導入例・制限を両言語README/helpへ記載し、未実装を提供済みと書かない。
- [ ] 任意依存がゼロでも基本表示・ナビゲーションが動き、不足する画像等はhealthで確認できる。
- [ ] 未保存編集、原文無変更、yank/search、複数window、resize/close、旧非同期結果、キーマップ/statusline保持を統合検証する。
- [ ] 1000ページ規模のfixtureで初期/再解析の時間を記録する。WezTerm/Ghosttyの手動確認結果と未検証構成を残す。
