# [I00] 共通契約・headlessテスト基盤

## 目的

位置・世代・エラー表現・各入力例が揃い、Neovim 0.12でテストを実行可能。

## 入出力と対象範囲

DocumentSnapshot（buffer・changedtick・ブロック/inline/見出し/リンク/表）、SourceRange、RenderedDocument（行・装飾・範囲対応・画像配置）、NavigationSnapshot、Session、取消可能providerを定義する。ミニマップ注釈は原文範囲と種類・重大度・provider IDを持つ。

全機能の空実装を量産しない。設定・公開コマンドの接続はI27。

## 先行Issue

なし。最初に実装して契約を確定する。

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/types.lua、tests/helpers/、tests/contracts/、共通テスト起動設定

専用テスト・fixture: `tests/i00/`。I00では共通契約・テスト起動だけを確定する。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] 契約fixtureだけでparser/renderer/nav/providerの入出力を読み合わせられる。空・エラー・未対応・partialを区別する。
- [ ] SourceMapは行対応だけでなく原文byte列・表示byte列・要素全体の対応を保持できる。変更世代と破棄済みSessionを識別できる。
- [ ] テスト起動方法を記載し、GUIやネットワークなしにheadless Neovim 0.12で契約検証が通る。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
