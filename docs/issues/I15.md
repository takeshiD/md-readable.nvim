# [I15] 読書Sessionと原文同期

## 目的

同一window・vert・float、カーソルとページの双方向同期、未保存内容保持、同期ループ防止、終了処理。

## 入出力と対象範囲

原文buffer/window、描画結果、NavigationSnapshot、表示方式 → 読書Session。

公開コマンド登録はI27。

## 先行Issue

- [I02 #3](https://github.com/takeshiD/md-readable.nvim/issues/3)
- [I03 #4](https://github.com/takeshiD/md-readable.nvim/issues/4)
- [I04 #5](https://github.com/takeshiD/md-readable.nvim/issues/5)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/reader/{session,projection,sync}.lua

専用テスト・fixture: `tests/i15/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] current/vert/floatで原文を保持し、同一起点・同一方式の再実行では既存表示を再利用する。
- [ ] カーソルとページ移動が双方向同期し、未保存編集をdebounceして描画へ反映する。プログラム移動による同期ループを起こさない。
- [ ] 異なる文書のSessionや複数windowの状態を混同せず、明示anchorを読書位置復元より優先する。
- [ ] close/resize/外部buffer変更でtimer・autocmd・非同期処理を破棄/更新し、Neovim終了をまたぐ保存はしない。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
