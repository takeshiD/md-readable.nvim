# [I04] ナビゲーション共通モデル

## 目的

重複参照、本文を持つ親、無効項目、複数tree、先頭末尾の規則を検証。

## 入出力と対象範囲

NavigationSnapshotと文書の利用可否 → 検証結果、索引、現在出現、祖先、読み順、previous/next。

SSG構文やUI配置を知らない。

## 先行Issue

- [I00 #1](https://github.com/takeshiD/md-readable.nvim/issues/1)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/navigation/{model,index,order}.lua

専用テスト・fixture: `tests/i04/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] 重複ID・循環・不正targetを診断し、正常な空目次と解析失敗を区別する。
- [ ] 本文を持つ親→子の深さ優先順。カテゴリ・外部URL・不在文書・unavailableを移動順から除外する。
- [ ] 同じファイルの複数出現を保持し、選択履歴→選択treeの最初の出現の順に現在地を解決する。
- [ ] 先頭末尾で循環せず、未掲載文書では前後ページを無効にする。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
