# Introduction

**Lumen** is a tiny static site generator for notes and handbooks. \
It turns a folder of Markdown files into a fast, searchable website.

> This handbook is itself a Lumen project. Every page you read here
> is a plain Markdown file in `src/`.

## Who is this for?

- Writers who want a website without learning a web framework.
- Teams that keep their documentation next to their code.
- Anyone who prefers plain text over a database.

## How to read this book

The **User Guide** walks you from installation to your first deployment. \
The **Reference** lists every command and configuration key. \
Use the previous / next links at the bottom of each page to read in order.
