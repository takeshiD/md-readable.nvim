# [I02] 原文と表示の範囲対応

## 目的

折返し・省略・リンク・表・表示専用装飾を扱い、原文コピーと双方向移動の範囲を解決できる。

## 入出力と対象範囲

rendererが出す対応segment → source_to_display / display_to_source / selection_to_source。文字の直接対応、要素全体、省略、原文のない装飾を区別する。

実際のyankやwindow移動はI19/I15。

## 先行Issue

- I00（起票時にGitHubリンクへ置換）

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/reader/source_map.lua

専用テスト・fixture: `tests/i02/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] `[導入手順](installation.md)`の表示で「導入」だけなら導入、全ラベルなら原文リンク全体の範囲を返す。
- [ ] 省略記号を含むセル選択はセル全体、表示部分だけの選択は対応部分へ解決する。
- [ ] 折返し・展開・表の整列・画像の空き行・日本語byte列で往復移動が正しく、表示専用の罫線には架空の原文を返さない。
- [ ] 古いchangedtickの座標を拒否し、選択結果の原文範囲を重複なく返す。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
