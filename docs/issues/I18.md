# [I18] 表の原文整形

## 目的

左/中央/右寄せ、全角・結合文字・escaped pipeを扱い、明示実行だけで変更、undo一回で復元、同じ整形の再実行で差分なし。

## 入出力と対象範囲

原文のTable構造と整形設定 → 原文の編集範囲と置換テキスト。

行列挿入削除はI29。共有parserの再実装は禁止。

## 先行Issue

- I01（起票時にGitHubリンクへ置換）

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/table/format.lua

専用テスト・fixture: `tests/i18/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] 左/中央/右寄せを区切り行に反映し、全角・tab・結合文字・escaped pipe・inline codeを破損させない。
- [ ] 同じ入力を再整形しても差分なし。差分がない場合はbufferを更新しない。
- [ ] 明示操作でだけ適用し、一回のundoで戻る。外部formatterやvim-table-modeは不要。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
