# [I16] 目次・見出し・前後ページUI

## 目的

3配置を設定可能、既定は統合ツリー、キーボード操作、現在地追従、本文への復帰、狭幅対応。

## 入出力と対象範囲

Sessionのbook tree/outline/current state → UIと選択action。

パーサーとSSG設定をUI内で読まない。

## 受け入れ条件

- [ ] 統合ツリー・左右分離・必要時表示を同じcoreで提供し、見出し展開で書籍の読み順を変えない。
- [ ] j/k・Enter・h/l・qで操作でき、項目の選択移動だけでは本文をジャンプさせない。本文へ復帰できる。
- [ ] 現在ページ・見出しを追従し、UI操作中に選択カーソルを奪わない。再解析でも展開状態を保つ。
- [ ] 80/120列、長い日本語タイトル、複数tree、Nerd Fontなし、既存statuslineを保持した状態で確認する。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。
