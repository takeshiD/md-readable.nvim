# [I31] ミニマップのLSP診断

## 目的

ERROR/WARN/INFO/HINT、severity filter、原文範囲から表示へ写像、更新と消去、診断のないbufferでも本体動作。

## 入出力と対象範囲

原文bufferのvim.diagnosticの結果と変更通知 → 重大度付き注釈。

LSP clientやlanguage serverを実装・自動導入しない。

## 受け入れ条件

- [ ] ERROR/WARN/INFO/HINTとseverity filterを提供し、DiagnosticChanged等により更新する。
- [ ] 原文範囲をSourceMapで表示に写し、折返し/省略後も対応位置へ表示する。
- [ ] 同じ縮小行では最も重大な診断を優先し、Git注釈とは区別する。診断解消・buffer破棄で消去する。
- [ ] 診断未提供の文書でもミニマップが動作し、追加LSP設定pluginを必須にしない。
