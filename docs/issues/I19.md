# [I19] 原文コピーと原文検索

## 目的

通常`/`は表示検索、`y`は原文コピー、省略部分も原文検索可能。選択規則・レジスタ・原文無変更を検証。

## 入出力と対象範囲

読書bufferの選択/検索要求とSourceMap → 原文レジスタ内容または検索結果への移動。

検索を原文へ無条件にリマップしない。

## 受け入れ条件

- [ ] 通常の/・?・n/Nは表示テキストの検索を維持し、専用原文検索は省略内容も対象にする。
- [ ] リンク部分→部分文字列、ラベル全体→原文リンク全体、省略記号を含むセル→セル全体を実際のyで検証する。
- [ ] 文字/行/矩形選択、count、指定レジスタ、折返し行の重複除去を検証し、装飾だけならレジスタを変更しない。
- [ ] 原文検索結果を選ぶと必要な箇所を表示し、未保存原文の更新後も古い範囲を使わない。原文を変更しない。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
