# 参考プラグインの機能を内蔵する

md-render.nvim、limelight.vim、vim-table-mode、neominimap.nvimは参考実装として扱い、今回の対象機能を本プラグイン内に実装する（Q18・Q20）。4プラグインへの委譲は初期実装を減らせる一方、読書表示の範囲対応・原文コピー・同期・windowごとの配色とFocusを一貫して扱う必要があるため、保守対象が増えることを受け入れて内蔵を選ぶ。

この判断は外部ツールや連携先の任意依存を禁止するものではない。Telescope / Snacks連携にはそのpickerを、画像・Mermaidには必要な描画ツールを利用できる。コードを再利用する場合はライセンスと著作権表示を保持する。
