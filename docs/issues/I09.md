# [I09] HonKit対応

## 目的

静的JSON設定、root、summary位置、章階層を解釈し、動的設定は診断。

## 入出力と対象範囲

静的book.json等と指定SUMMARY → NavigationSnapshot/diagnostics/dependencies。

HonKitビルドを起動しない。

## 受け入れ条件

- [ ] root変更、指定summary、ネスト章、空目次、未解決pathを検証する。
- [ ] 動的設定・plugin生成結果は標準対応と混同せず、providerへの経路を案内する診断を返す。
- [ ] SUMMARY共通parserを使い、HonKit固有の意味付けをadapter内に閉じ込める。
- [ ] 対象設定の具体的な構文・非対応構文・確認した公式資料と版を記録し、正常系/未対応/root変更/順序/実在文書への対応のfixtureを揃える。名前だけの対応は完了としない。
