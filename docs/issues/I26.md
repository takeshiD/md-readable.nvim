# [I26] リンク一覧とリンク操作

## 目的

種別を色以外でも区別、一覧から原文/移動先へ移動、未解決を診断、URL省略後も原文対応を保持。

## 入出力と対象範囲

共通Link構造とSession/root/adapter → 種別、解決済みtarget、移動action。

URLをshell/Ex文字列へ無加工連結しない。

## 先行Issue

- I01（起票時にGitHubリンクへ置換）
- I04（起票時にGitHubリンクへ置換）
- I15（起票時にGitHubリンクへ置換）

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/navigation/resolver.lua、lua/md-readable/ui/links.lua

専用テスト・fixture: `tests/i26/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] local document/same-page anchor/external URL/asset/unresolvedを色以外の印でも区別する。
- [ ] 空白・日本語・相対path・query・anchorを混同せず、同名見出しやSSG固有slugの扱いを検証する。
- [ ] 文書中リンク一覧から原文位置と移動先を選び、ローカル文書のページ移動は原文と読書を同期する。
- [ ] 未解決anchorを適当な位置へ飛ばさず診断する。外部URLは明示操作で開く。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。
