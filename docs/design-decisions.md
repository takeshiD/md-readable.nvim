# 要件整理の対話記録

## 記録の扱い

この節は2026-10-03からの対話で確認した内容を記録する。従来の細部には暫定案が残っているため、矛盾する場合はこの節の合意を優先する。未回答の事項を実装要件として確定しない。

### 第1ラウンド（2026-10-03）

- Q1・主用途: 他人のREADMEや長いMarkdownを読んで理解すること、およびSSGの書籍・ドキュメントを章を行き来しながら読むこと。自分の文書の推敲は主用途ではないが、既存の執筆支援要件は残す。
- Q2・表示目標: 完成した文書に近い読書表示を目指す。画像・図の本文内表示や表示上の配置変更も重視する。具体的な表示方式、記法の対応範囲、既定レイアウトは次のラウンド以降で決める。
- Q3・必須範囲: READMEと本設計書に列挙した機能は候補ではなく、実装する約束とする。Appearance、Navigation、Formatting、Contents、Writingの全領域、見出しツリーとミニマップの両方、SSG全7対象（Zensicalを含む）を実装対象に残す。段階分けは実装順序であり、後続機能の削除や任意化を意味しない。形式ごとの互換範囲・受け入れ条件は引き続き具体化する。
- Q4・環境と導入: ターミナルNeovimを主対象とする。基本機能に特定端末・Nerd Font・クラウド・SSGビルド・Node.js・Pythonを要求しない。画像・Mermaidの外部ツールは任意導入とし、利用できない環境でも基本機能は成立させる。読むだけでは原文を変更せず、整形は明示操作とする。

### 第2ラウンド（2026-10-03）

- Q5・読書開始: 機能をコマンドとして提供し、キーマップや自動実行への割り当てはユーザーが自由に設定する。同じウィンドウで読書表示へ切り替える方式と、原文と読書表示を並べる方式の両方を提供する。`MdReadable vert`で縦分割して左右に原文と読書表示を置き、`MdReadable float`でfloating windowに読書表示を開く。引数なしの動作や終了・再実行時の詳細は後続で確定する。
- Q6・再現範囲: Markdownに加えて、注意書き・折りたたみ・タブなど一般的な拡張表現を読みやすく表示する。サイト独自のコンポーネントは原文を確認できるようにする。具体的な記法や見た目は初期実装がある程度完成してから見直すため、初期仕様と将来の調整を区別する。
- Q7・画像と図: 必要な端末機能・外部ツールが利用可能なら、画面内に入った画像・Mermaidを本文内に自動表示する。外部画像の取得方針は別途決める。
- Q8・ナビゲーション配置: configで配置を変更できるようにする。既定は書籍目次と現在ページの見出しを左側に統合したツリー。ミニマップは既定では非表示とし、操作で開閉する。
- Q9・SSG対応: 全7対象について、ローカル文書と静的設定を標準対応とし、動的な生成結果は共通形式の目次などを渡す拡張経路で扱う。公開サイトの動的生成結果の自動再現は標準対応の完成条件に含めない。対象ごとの入力形式と受け入れ例を明記する。

### 第3ラウンド（2026-10-03）

- Q10・同期: 原文と読書表示は、同一文書内のカーソル位置だけでなく、ページ移動も双方向に同期する。読書側で別の章へ移動したら原文側も同じ文書へ切り替える。未保存内容は保持する。
- Q11・表: 列幅を抑え、長いセルを省略して行の一覧性を保つ方式を採用する。セル全文を操作で確認でき、省略箇所を明示する。セルの折り返しや横スクロールへの切り替えは、この回答では追加要件として確定していない。
- Q12・Focus: ユーザー指定の参考実装`limelight.vim`と同じ動作を基準とする。従来のMarkdown意味ブロック単位という暫定案より、この指定を優先する。参照実装は空白行区切りの段落への追従、明示行範囲・Visual範囲での起動時の範囲固定、減光強度や前後段落数の設定を提供する。
- Q13・外部画像: 既定では取得しない。ユーザーの操作または設定によって取得を許可してから表示する。ローカル画像・Mermaidの自動表示方針は維持する。
- Q14・テーマ: 配色の切り替えは読書表示だけに適用する。原文や他のウィンドウのカラースキームは変更しない。
- Q15・読書位置: Neovim終了をまたぐ位置・状態の保存は不要とする。同一Neovimセッション内の状態保持は認めるが、翌回起動時の復元機能は実装範囲から外す。この明示的な変更は、第1ラウンドの全機能必須より優先する。

### 第4ラウンド（2026-10-03）

- Q16・検索: 読書表示の通常の`/`は表示テキストを検索する。原文全体を検索する専用コマンドも提供し、通常検索とは分ける。
- Q17・コピー: 読書表示からの標準`y`は対応する原文をコピーする。たとえばリンクラベル「導入手順」を選択した場合は`[導入手順](installation.md)`をコピーする。部分選択や省略領域の範囲対応は、受け入れ例を追加して具体化する。
- Q18・参考実装: AGENTS.mdに記載された参考プラグインを必須依存にしない。その機能を本プラグイン内に実装することを必須とする。参考プラグインのインストールを要求したり、機能を未実装のまま外部プラグインへの委譲で済ませたりしない。
- Q19・Focus適用先: 読書表示だけに適用する。原文・他のウィンドウへFocusが波及する参照実装の動作は採用しない。

### 第5ラウンド（2026-10-03）
