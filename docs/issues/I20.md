# [I20] Focus Mode

## 目的

Limelightの段落境界・span・Visual起動時固定範囲を再現し、読書表示以外を暗くしない。

## 入出力と対象範囲

読書windowのカーソル/明示範囲とFocus設定 → 対象行範囲・減光。

limelight.vimの必須依存・全windowへの適用はしない。

## 先行Issue

- [I15 #16](https://github.com/takeshiD/md-readable.nvim/issues/16)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/reader/focus.lua

専用テスト・fixture: `tests/i20/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] Limelightの空白行区切り・単一/連続空行・先頭末尾・前後段落spanをfixtureで照合する。
- [ ] Visual範囲を指定して起動した場合は選択行を固定し、単にVisualへ入った場合と区別する。
- [ ] 係数既定0.5、span既定0、境界pattern/色/priorityの設定、on/off/toggleを提供する。
- [ ] 原文や他windowは暗くせず、閉じる/テーマ変更/再描画で古いhighlightが残らない。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
