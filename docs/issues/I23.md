# [I23] Mermaid描画

## 目的

元コード保持、argvで描画、キャッシュ更新、可視領域で表示、失敗時にコードを読める。

## 入出力と対象範囲

原文のMermaid codeと世代/描画設定 → ローカル画像provider入力または元コードfallback。

PlantUMLは対象外。

## 先行Issue

- [I01 #2](https://github.com/takeshiD/md-readable.nvim/issues/2)
- [I22 #23](https://github.com/takeshiD/md-readable.nvim/issues/23)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/providers/mermaid.lua

専用テスト・fixture: `tests/i23/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] mmdc等の明示導入されたrendererをargvで実行し、画面内の図を自動描画する。
- [ ] npx等でツールを自動取得しない。renderer不在・構文エラー・取消しでも元コードを読める。
- [ ] 入力変更と設定変更でcacheを更新し、古い非同期結果を現在の図へ適用しない。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
