# [I30] ミニマップのGit差分

## 目的

原文の追加・変更・削除を表示へ写像、未保存変更も対象、差分解消時の消去、非Git/コマンド不在時も本体動作。

## 入出力と対象範囲

Git indexと未保存内容を含む原文buffer → 原文行範囲のadd/change/delete注釈。

Git履歴UIやコミット操作は対象外。

- [I02 #3](https://github.com/takeshiD/md-readable.nvim/issues/3)
- [I24 #25](https://github.com/takeshiD/md-readable.nvim/issues/25)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/minimap/git.lua

専用テスト・fixture: `tests/i30/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] Gitコマンドを使う内蔵入力を提供し、gitsigns/mini.diffのインストールを必須にしない。
- [ ] index基準の追加/変更/削除を検出し、原文→表示→縮小位置へ写像する。削除行が存在しない場合は近傍へ表示する。
- [ ] 未保存変更、index更新、差分解消、非Git文書、Git不在、古い非同期結果を扱う。
- [ ] 更新をまとめ、カーソル移動ごとにGit処理を起動しない。Gitや文書を書き換えない。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。
