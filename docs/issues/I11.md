# [I11] MkDocs対応

## 目的

docs_dir、明示nav、階層・外部リンク・順序を扱い、未対応タグ/拡張を診断。

## 入出力と対象範囲

mkdocs.ymlとdocs_dir内のローカル文書 → NavigationSnapshot。

YAML parserやUIをadapter内に作り直さない。

- I05（起票時にGitHubリンクへ置換）

lua/md-readable/adapters/mkdocs.lua

## 受け入れ条件

- [ ] 明示navの表示名・階層・順序・外部リンク・docs_dir変更を検証する。
- [ ] plugin・独自タグ・継承等の対応範囲を列挙し、対象外をpartial/unsupportedとして診断する。
- [ ] nav不在時に推測順をMkDocsと同じと宣言しない。
- [ ] 対象設定の具体的な構文・非対応構文・確認した公式資料と版を記録し、正常系/未対応/root変更/順序/実在文書への対応のfixtureを揃える。名前だけの対応は完了としない。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。
