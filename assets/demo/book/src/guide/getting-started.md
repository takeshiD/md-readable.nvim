# Getting Started

Create a new project and start the development server in two commands.

```sh
lumen new my-notes
cd my-notes && lumen serve
```

Open <http://localhost:3000> and edit `src/index.md`. \
The page reloads as soon as you save.

## Project layout

```text
my-notes/
├── lumen.toml      # project settings
├── src/
│   ├── SUMMARY.md  # table of contents
│   └── index.md
└── theme/          # optional overrides
```
