# [I28] Telescope / Snacks連携

## 目的

Markdown・画像preview、同一ファイル内の別grep結果への追従、元previewへのfallback、終了時cleanup、picker未導入時の本体ロード。

## 入出力と対象範囲

pickerのpreview context（path、source行、window） → Markdown/画像previewまたは標準preview。

動画previewは対象外。md-render.nvimに委譲しない。

- I03（起票時にGitHubリンクへ置換）
- I15（起票時にGitHubリンクへ置換）
- I22（起票時にGitHubリンクへ置換）

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/integrations/{telescope,snacks}.lua、lua/telescope/_extensions/md_readable.lua

専用テスト・fixture: `tests/i28/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] Telescope builtin/custom pickerに渡せるpreviewerとextension、Snacksの全体/個別sourceに渡せるpreview関数を提供する。
- [ ] find_files/files、live_grep/grep、grep_string等でMarkdown/画像を描画し、非対応fileは元previewへ戻す。
- [ ] 同一ファイルの別grep結果へ移動しても該当source行へ追従し、候補の高速切替・終了時に古い画像やjobを残さない。
- [ ] picker未導入で本体をロードでき、候補の検索や選択確定actionを乗っ取らない。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
