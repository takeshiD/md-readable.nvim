# [I21] 読書表示のテーマ

## 目的

読書表示だけ配色切替、ColorScheme追従、原文や別windowへ影響なし。

## 入出力と対象範囲

読書windowと配色設定/ColorScheme → 読書専用highlight。

Neovim全体のcolorschemeを切り替えない。

## 先行Issue

- [I03 #4](https://github.com/takeshiD/md-readable.nvim/issues/4)
- [I15 #16](https://github.com/takeshiD/md-readable.nvim/issues/16)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/ui/theme.lua

専用テスト・fixture: `tests/i21/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] 既定は現在のcolorschemeへ馴染む配色とし、読書用の明暗プリセット/ユーザー上書きを提供する。
- [ ] 同じ原文を別windowで開いても読書テーマが波及しない。
- [ ] テーマ変更後にコード・表・Focusの表示が更新され、無効化時に状態を片付ける。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。

仕様根拠: `md-readable_design.md`、`docs/final-spec-review.md`、`docs/implementation-issues.md`。4参考プラグインへの必須依存で実装を代用しない。別のworktreeで作業し、担当外の変更を上書きしない。
