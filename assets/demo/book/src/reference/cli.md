# Command Line

| Command        | Description                          |
| -------------- | ------------------------------------ |
| `lumen new`    | Create a new project                 |
| `lumen serve`  | Start the development server         |
| `lumen build`  | Render the site to `book/`           |
| `lumen check`  | Find broken links and missing pages  |

## Global flags

- `--quiet` hides progress output.
- `--root <dir>` runs as if started in `<dir>`.
