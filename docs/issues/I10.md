# [I10] GitBook対応

## 目的

ローカルSpace、設定されたroot/summary、複数treeを扱い、未同期文書は移動不可と表示。

## 入出力と対象範囲

ローカルGitBook設定とSpaceごとのSUMMARY → 複数treeのNavigationSnapshot。

クラウドAPI連携は対象外。

## 先行Issue

- [I04 #5](https://github.com/takeshiD/md-readable.nvim/issues/5)
- [I05 #6](https://github.com/takeshiD/md-readable.nvim/issues/6)
- [I06 #7](https://github.com/takeshiD/md-readable.nvim/issues/7)

先行は結合完了に必要な依存を表す。I00完了後は契約fixtureで先行実装できるが、モックだけで依存との結合確認を済ませない。

## 担当ファイル

lua/md-readable/adapters/gitbook.lua

専用テスト・fixture: `tests/i10/`。公開入口、設定、コマンド、README/helpの接続はI27へ引き継ぎ、この担当から同時編集しない。 共通契約を変える場合は統合担当と先に調整する。

## 受け入れ条件

- [ ] gitbook-docs.yaml/.gitbook.yamlの対象構文、root/summary変更、ページグループ、ネストを検証する。
- [ ] ローカルにないSpaceやページは移動不可と診断し、クラウドから勝手に取得しない。
- [ ] Spaceごとのtreeと現在地を混在させず、実在文書への対応を保つ。
- [ ] 対象設定の具体的な構文・非対応構文・確認した公式資料と版を記録し、正常系/未対応/root変更/順序/実在文書への対応のfixtureを揃える。名前だけの対応は完了としない。

## 検証と引き継ぎ

対象のheadlessテストと関連する結合テストを実行し、実行コマンド・結果・未確認点を記載する。端末画像等の実表示が必要な場合は手動検証を区別し、実施していない結果を成功と記載しない。追加する設定・コマンド・任意依存とcleanup契約をI27へ引き継ぐ。
